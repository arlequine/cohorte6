# Configuración de MCP

Este ejemplo (ruta B de la Estación 9) usa los mismos tres servidores que la ruta del programa: Terraform, AWS Documentation y LocalStack. La configuración para Claude Code, Cursor, Codex, GitHub Copilot y Antigravity está en [`../../producto-desplegado/mcp/README.md`](../../producto-desplegado/mcp/README.md#estación-9-terraform-aws-documentation-y-localstack).

Copia el bloque de tu herramienta al archivo que corresponda en la raíz de este repo (por ejemplo, `.mcp.json` para Claude Code). No subas tokens: exporta `LOCALSTACK_AUTH_TOKEN` en tu terminal.
